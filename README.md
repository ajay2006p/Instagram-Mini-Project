# 📸 Instagram Mini Project

An **Instagram-inspired mini social media application** developed in **Java** to explore and apply core programming concepts and application logic.

---

## 🚀 Overview

This project is a console/logic-based recreation of fundamental social-media features, built as a learning exercise to strengthen object-oriented programming and core Java skills. It focuses on clean logic and the building blocks behind a real social platform.

## ✨ Features

- 👤 **User Management** — create and manage users.
- 🖼️ **Post Handling** — create and manage posts.
- 💬 **Basic Interactions** — core social interactions implemented through Java logic.
- 🧠 **Concept-Focused** — designed to practice OOP principles and application flow.

## 🧰 Tech Stack

| Layer | Technology |
| -------- | ---------- |
| Language | Java       |
| Concepts | OOP, Core Java |

## ⚙️ Getting Started

### Prerequisites

- [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/) installed (JDK 8 or higher).

### Run the Project

```bash
# Clone the repository
git clone https://github.com/ajay2006p/Instagram-Mini-Project.git

# Move into the project directory
cd Instagram-Mini-Project

# Compile the Java source
javac index.java

# Run the program
java index
```

## 🎯 Purpose

This project was built primarily as a **learning project** to master core Java programming concepts, object-oriented design, and application logic — laying a strong foundation for larger applications.
